# Poshak Habibi

ERP / shop app (Django API + React frontend).

## Windows client install

See **[WINDOWS_SETUP.md](WINDOWS_SETUP.md)**.

Quick start (after Python **3.12/3.13** + Node.js LTS are installed):

```bat
scripts\windows\setup.bat
scripts\windows\create-admin.bat
scripts\windows\start-all.bat
```

Then open http://localhost:5173

**Note:** Python **3.15 is not supported** by this project’s Django version. Use 3.13.
